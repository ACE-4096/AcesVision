# =============================================================================
# track_video.py runs in this repo's own .venv. Nothing else is needed:
#
#   .venv/bin/python track_video.py <video.mp4> --annotated <out.mp4>
#
# app_track.py additionally needs Gradio, which is NOT part of this file and is
# NOT installed by default — install it before using the UI:
#
#   .venv/bin/pip install gradio
#   .venv/bin/python app_track.py            # http://127.0.0.1:7860
#
# GPU stack (installed in .venv, see README "Runtime: one venv"). Install these
# from the ROCm index, never from PyPI — PyPI's torchvision pulls a CUDA torch
# in behind it and silently replaces the ROCm build:
#
#   torch==2.9.1+rocm6.3         (AMD RX 6600, HSA_OVERRIDE_GFX_VERSION=10.3.0)
#   torchvision==0.24.1+rocm6.3
#   ultralytics==8.4.60          (YOLO + ByteTrack/BoTSORT, installed --no-deps)
#
#   .venv/bin/pip install torch==2.9.1+rocm6.3 torchvision==0.24.1+rocm6.3 \
#     --index-url https://download.pytorch.org/whl/rocm6.3
#   .venv/bin/pip install --no-deps ultralytics==8.4.60
#
# HSA_OVERRIDE_GFX_VERSION is set automatically by watch.sh and by the YOLO
# worker, and only on a host that actually has the AMD stack loaded.
#
# History: these tools once required a separate ROCm venv on an external drive,
# because the root filesystem was full. That drive is gone, the root filesystem
# is not full, and there is no second venv. Do not reintroduce one.
